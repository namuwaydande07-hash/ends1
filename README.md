# SkillUp – Online Skill Development Platform
## CO5K ENDS Entrepreneurship Micro Project

A responsive educational website prototype with course catalog, demo enrollment, browser-based learning progress, sample quizzes, printable demo certificates, business plan, and editable financial estimates.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For best results, use VS Code with the Live Server extension, then choose **Open with Live Server**.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Open repository **Settings → Pages**.
4. Select deployment from the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish the site.

## Important limitations
- Enrollment and lesson progress use browser `localStorage`; they are stored only in that browser and are not a shared database.
- There is no secure student authentication, real payment processing, server-side admin system, or actual email delivery.
- Course content, testimonials, pricing, and financial figures are examples for a college demonstration.
- The printable certificate is a demonstration certificate, not an accredited qualification.

## Business model
Potential revenue sources include paid courses, subscriptions, optional certificates, and future corporate training. The Financial Plan section lets the user adjust monthly sales, average price, expenses, and variable cost to calculate illustrative revenue, costs, surplus/loss, and break-even sales.

## Main features to test
- Search courses and filter by category.
- Enroll in a course and find it under My Learning.
- Mark lessons complete and see progress update.
- Take a quiz and review the saved score.
- Complete all sample lessons and print a demonstration certificate.
- Change financial assumptions and check recalculated results.
- Submit the contact form and see its demo-only status message.
